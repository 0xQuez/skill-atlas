# Hugging Face publish pack

Prepared, not uploaded. Nothing in this folder is public until you run `publish.sh` with a token.

## Layout

- `dataset/` — dataset card plus (on disk, gitignored) the Parquet and sidecar files to upload
- `space_api/` — Docker Space (port 7860) for the JSON API and MCP tools
- `space_dashboard/` — static Space for the website; the built files are generated by `publish.sh`
- `publish.sh` — creates the dataset and both Spaces as **private** repos and uploads. You can make them public later from the Hugging Face UI.

## What you need

- A Hugging Face account and a token with write access (`HF_TOKEN`)
- The Hugging Face **username** (it may not be the same as the GitHub account `0xQuez`)
- `huggingface_hub` installed (already in this project's `.venv`)

Default repo names, which you can change:

| Kind | Default id |
|---|---|
| Dataset | `$HF_USER/skill-atlas` |
| API Space | `$HF_USER/skill-atlas-api` |
| Dashboard Space | `$HF_USER/skill-atlas-web` |

## Run (when you are ready)

```bash
export HF_TOKEN=...          # do not paste this into chat
export HF_USER=your-hf-username
./hf_publish/publish.sh
```

The script will not make the repos public. After you have looked at the private Spaces, you can switch them to public in the Hugging Face settings, then fill in `HOSTED_DATASET_URL`, `HOSTED_API_URL` and `HOSTED_DASHBOARD_URL` in the git README.
